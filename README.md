# HCMUS GPA Calculator Bookmarklet
**A modern bookmarklet toolkit for the HCMUS Student Portal**

## Guideline
- Step 1: You must be an HCMUS student.
- Step 2: Open **[this link](https://dorayakiiiiz.github.io/GPABookmarklet)** to drag and drop the bookmarklet into your browser bookmarks bar.

```
https://dorayakiiiiz.github.io/GPABookmarklet
```

## Key Features
- **Academic Results**: View cumulative GPA (Scale 10 & 4), simulate expected scores, plan graduation/semester targets, filter by academic years, and export styled transcripts to Excel/PDF.
- **Course Offerings**: Interactive timetable planning with lab/tutorial slot selection, filtered by day and cohort.
- **Registration Results**: Auto-render visual weekly schedules from approved course enrollments.
- **Course Registration**: Auto-match pre-saved schedules from the planner, grab remaining slots, and confirm registration seamlessly.
